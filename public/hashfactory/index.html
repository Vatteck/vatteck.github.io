Current rebuild

A clean foundation for a story that scales.

Interface

Kotlin + Jetpack Compose

A thin Android shell presents the state; it does not hide simulation rules inside UI code.

Simulation

Deterministic core

The game advances through a pure simulation over one immutable GameState, covered by unit tests.

Economy

Capacity, not free income

Hardware helps process assigned work. It never mints wallet income by itself.

Persistence

Saves with a future

Schema changes require explicit migration paths and frozen-fixture coverage.
